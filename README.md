# Kata 1 – Creación de clases y objetos en Java

**Asignatura:** Ingeniería de Software 2  
**Universidad:** Universidad de Las Palmas de Gran Canaria (ULPGC)  
**Repositorio:** https://github.com/estherviera/kata1  
**Rama principal de entrega:** `master`

## 1. Objetivo

El objetivo de esta kata es practicar la creación de clases y objetos en Java, utilizando constructores, atributos y métodos.

La práctica permite reforzar los conceptos básicos de programación orientada a objetos, la organización del código y el uso de herramientas de desarrollo.

## 2. Tecnologías utilizadas

- Java (JDK 27, según `pom.xml`).
- IntelliJ IDEA como entorno de desarrollo.
- Maven para la gestión del proyecto.
- Git y GitHub para el control de versiones.

## 3. Estructura del proyecto

El código está organizado dentro del paquete `software.ulpgc.kata`.

### `software.ulpgc.kata`

- **Person:** clase que representa a una persona mediante sus atributos y su constructor, permitiendo crear objetos con diferentes datos.
- **Main:** clase principal desde la que se crean y utilizan los objetos de tipo `Person` para comprobar su funcionamiento.

## 4. Compilación y ejecución

### Requisitos

Tener instalado un JDK compatible con la versión configurada en `pom.xml` y Maven.

### Pasos

1. Clonar el repositorio:

   ```bash
   git clone https://github.com/estherviera/kata1.git
   ```

2. Abrir el proyecto en IntelliJ IDEA.

3. Cargar el proyecto Maven mediante el archivo `pom.xml`.

4. Compilar el proyecto:

   ```bash
   mvn compile
   ```

5. Ejecutar desde IntelliJ IDEA la clase principal:
   - `Main`: creación de objetos `Person` y ejecución de las operaciones implementadas para comprobar su funcionamiento.
